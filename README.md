# Actividades SENA

El propósito de este repositorio es recopilar las actividades de programación durante el desarrollo de la tecnología **Análisis y Desarrollo de Software - ADSO**.

El objetivo es, básicamente, definir una trayectoria de los proyectos realizados y, de la misma manera, crear retos personales. Los principales serían:

* **Buenas prácticas:** Intentaré aplicar buenas prácticas al mantenimiento de repositorios de GitHub y de los proyectos desarrollados en el mismo.
* **Comparativa de lenguajes:** La idea principal es desarrollar la mayoría de los ejercicios en lenguajes de programación diferentes para reforzar el conocimiento de entornos que no uso mucho, entre ellos:
  1. JavaScript
  2. Java
  3. Rust
  4. C#
  5. Bash

## Estructura del repositorio

El repositorio contendrá los directorios pertenecientes a cada competencia. Dentro de ellos habrá un subdirectorio referente a cada lenguaje y un archivo guía en formato Markdown (`README.md`) donde se describen los ejercicios planteados, diagramas arquitectónicos y la metodología de su solución.
